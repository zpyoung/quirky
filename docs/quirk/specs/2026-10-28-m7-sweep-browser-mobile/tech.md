## Architecture and contracts
Reuse MobilePreferences.terminalLinkMode ('desktop'|'phone'), createMobileRpc, route/grant bridge and quirky.mobile/browserWatchCreate({worktree:string,url?:string}) returning {tab:MobileWorkspaceTab,watchId:string}. A SessionPage link handler selects only that returned real tab in the current worktree. TerminalView receives an owner callback for desktop links; it must not introduce a second preference or directly create a lease. Normalize/validate safe http(s) URL before any launch; no inferred Native conversion or phone fallback. Settings labels the mode Chrome Watch and saves the existing enum; keep Phone default. Guard duplicate pending creation and stale route/connection/unmount completion. Never release a foreign consumer lease.

Lifecycle amendment (logic S6): preserve PageBridgeHost.close():void. Track exact terminal stream and mobile Watch acquisitions by the actual captured MobileRpc, connection epoch and returned identity. Close/setRpc stop page delivery immediately and reclaim completed or late successful acquisitions using that original RPC without closing it. Exact successful detach/stop retires ownership. Shared same-lease adoption across page-host instances on one persistent RPC must prevent old cleanup from revoking newer active ownership; use bounded per-host references keyed by actual RPC/resource identity where needed. Never authorize cleanup from malformed/failed replies or guessed page parameters. MobileContracts owns this shell-only repair and its actual encrypted lease-state regression; no web-entry or PhoneLinks file overlap.

Tab-count contract (logic S7): new public quirky.terminal/tabCounts({}) is readOnly and returns TerminalTabCounts: {counts:Array<{worktreeId:string,tabCount:number}>,unavailableWorktrees:string[]}. Counts include only current actual layout tabs, across groups; split panes, background sessions and closed history are not new tabs. Run in LayoutService's existing queue over loaded cold/hot owner models and unreadable IDs, with no ensure/reconcile/open operation requested by the method. Missing ID in a complete valid snapshot means zero unless listed unavailable. Return no titles, URLs, args, paths or session data; no persistent migration/cache. Declare strict empty params and count-only result schema plus CLI words `terminal tab counts`.

Phone count consumption: admit only this empty-parameter read method under existing rpc+terminal grants on the Workspaces route, not unrelated panel/artifact routes. Add literal daemon/page method entries and validators, without generic namespace access or new grants. Read one batch per existing workspace load; generation-bound updates cannot overwrite newer data or update an unmounted page. Failed, malformed, duplicate-ID or unavailable snapshots omit the number without breaking the workspace list; never fall back to sessionRows.length as tabs. Session count remains a separately labeled property.

Feedback contract (logic S8): parent owns only SessionPage.tsx and styles.ts for intrinsic-height wrappers. Retain qp-content gutters with a narrower qp-session-feedback override (no flex growth, no extra body scrolling/padding); no message/route/resource semantics change. Actual390px UI evidence, not CSS/source-text tests, closes this defect.
